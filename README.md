Μαθαίνοντας Δομές Δεδομένων! 

Αυτό το έργο είναι ένα εκπαιδευτικό διαδραστικό περιβάλλον αξιολόγησης και εξάσκησης για την εκμάθηση δομών δεδομένων (όπως Πίνακες, Στοίβες, Ουρές, Λίστες, Δέντρα, Σωροί και Αλγόριθμοι Ταξινόμησης). Απευθύνεται σε μαθητές 8–14 ετών και περιλαμβάνει γραφικές ανιματίσεις, quiz και στοιχεία περιπέτειας 12 επιπέδων. Αναπτύχθηκε στα πλαίσια του μαθήματος "ΔΙΔΑΚΤΙΚΗ ΤΗΣ ΠΛΗΡΟΦΟΡΙΚΗΣ" του 8ου εξαμήνου, στο Τμήμα Εφαρμοσμένης Πληροφορικής.

## Τεχνολογίες

* Χρησιμοποιήθηκαν HTML5, CSS3, JavaScript (Vanilla ES6+) και Google Fonts (Nunito, Fredoka One).


* Δεν χρησιμοποιήθηκε κανένα framework ή εξωτερική βιβλιοθήκη.



## Οδηγίες Εκτέλεσης

* Το λογισμικό είναι πλήρως offline και δεν απαιτεί εγκατάσταση ή σύνδεση στο διαδίκτυο.


* Ανοίξτε το αρχείο `data-structures-kids.html` με οποιοδήποτε σύγχρονο πρόγραμμα περιήγησης (Chrome, Firefox, Edge).
